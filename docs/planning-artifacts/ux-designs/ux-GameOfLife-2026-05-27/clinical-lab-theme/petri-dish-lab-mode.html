Clinical Lab Theme - Lab Mode: This design transforms the biotech terminal aesthetic into a clean, professional laboratory equipment interface. The design uses a sans-serif font family for modern readability, sharp borders without glows or shadows for precision, and tight letter-spacing on titles for a clinical feel. The cyan accent color (#00d4ff) is reserved for interactive elements and highlights. The layout maintains all functionality from the biotech terminal version: organism selection with search and dropdown, eraser tool, grid manipulation tools, real-time statistics, and zoom controls. The primary action (SAVE) uses a solid cyan background to clearly indicate importance. The minimalist approach eliminates decorative effects like scan lines and terminal animations, focusing user attention on the scientific task of organism placement and observation. All organism colors are preserved from the original design. Navigation between lab/play modes and back to battle gallery is fully functional.
