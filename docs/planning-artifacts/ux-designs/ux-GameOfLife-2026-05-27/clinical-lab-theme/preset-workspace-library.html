Epic 7 (FR-9) — Preset Workspace Library & Descriptions, Clinical Lab theme. Everything reuses existing patterns: the preset row is a settings-item like Import (select + secondary button); the warning dialog is FR-8.4's destructive-replace copy with the preset name in the title; descriptions are quiet supporting text — clamped to 2 lines on tiles/cards, full under the Play-Mode header, one workspace line under the gallery title. An absent description renders nothing (see the Glider Run tile). The first-visit path deliberately has no UI at all — the populated, described gallery is the entire experience.
