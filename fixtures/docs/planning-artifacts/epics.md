# Epics

## Epic 1: Project Setup

- **1-1-project-scaffold** — Bootstrap the app skeleton, tooling, and lint/format config.
- **1-2-ci-pipeline** — Wire up CI to run lint, typecheck, and tests on every push.

## Epic 2: Authentication

- **2-1-login-page** — Email/password login form with client-side validation.
- **2-2-signup-flow** — New-account signup, including email verification.
- **2-3-password-reset** — Forgot-password flow via a one-time emailed link.

## Epic 3: Dashboard

- **3-1-dashboard-layout** — Top-level dashboard shell reusing the app scaffold.
- **3-2-widget-grid** — Draggable widget grid showing per-account summary data.
